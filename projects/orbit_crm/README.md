# Orbit CRM — IndexedDB edition

A responsive single-page CRM built with Tailwind CSS v4, DaisyUI v5, Material Symbols Rounded, and IndexedDB.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox, or Safari).
3. Internet connection is needed to load the CDN libraries.
4. Add records. They are automatically saved to IndexedDB in that browser profile.

## Included
- Dashboard with revenue, contacts, leads, pipeline metrics and charts
- Contacts, leads, tasks and companies CRUD
- Sales pipeline with deal stages
- Reports and analytics
- Workspace settings and currency preference
- JSON backup export and restore/import
- Optional sample data

## Important data note
IndexedDB stores data locally in the browser on the current device/profile. It is not automatically synchronized between different devices or browsers. Use **Backup** to download a JSON file regularly, and **Restore** to import it later. Clearing browser site data can remove local CRM records.
